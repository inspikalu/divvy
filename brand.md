# Brand Guidelines — Divvy

_Status: active_

## 1. Brand Identity
- **Product Name**: Divvy
- **Tagline**: Hold the Meme, Earn the Stock / Automated On-Chain Dividend Routing for Meteora Dynamic Bonding Curves
- **Core Value Proposition**: Permissionless dividend routing layer enabling Meteora DBC meme token creators to stream accumulated swap trading fees to token holders pro-rata in high-quality quote assets (e.g. xSTOCK, USDC).

## 2. Color Palette
- **Primary Accent**: Pastel Brand Purple
  - `brand-50`: `#faf5ff`
  - `brand-100`: `#f3e8ff`
  - `brand-200`: `#e9d5ff`
  - `brand-300`: `#d8b4fe`
  - `brand-400`: `#c084fc`
  - `brand-500`: `#a855f7`
  - `brand-600`: `#9333ea` (Primary Action & Accent)
  - `brand-700`: `#7e22ce`
  - `brand-800`: `#6b21a8`
  - `brand-900`: `#581c87`
  - `brand-950`: `#3b0764`
- **Surface & Backgrounds**:
  - Background Canvas: `#f8fafc` (`bg-surface-bg`)
  - Panels & Cards: `#ffffff` (`bg-white`)
  - Hairline Borders: `#e2e8f0` (`border-slate-200`)
  - Subtle Wells: `#f8fafc` (`bg-slate-50`)
  - High Contrast Hero: `#020617` (`bg-slate-950`)
- **Semantic Accents**:
  - Success / Live: Emerald (`#10b981`)
  - Warning / Alert: Amber (`#f59e0b`)
  - Error: Rose (`#f43f5e`)

## 3. Typography
- **UI & Body**: Sans-serif (`Inter`, `ui-sans-serif`, `system-ui`)
- **Data, Numbers & Addresses**: Monospace (`ui-monospace`, `JetBrains Mono`, `Geist Mono`, `font-mono`) with `tabular-nums`

## 4. UI Patterns & Craft
- Structured flat hairline containers (`border border-slate-200 divide-slate-200 rounded-xl`)
- Clear visual hierarchy with dominant data numbers in monospace
- High-contrast hero banners using pure black and white CTAs
- Responsive grid pattern canvas background (`.bg-grid-boxes`)
